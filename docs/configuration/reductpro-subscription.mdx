# ReductPro subscription

This page explains how to activate and manage a ReductPro subscription on a self-hosted ReductStore instance.

## Get your license key

The license server creates your checkout and, once payment is confirmed, provisions your license for the subscription.

## Configure the license key

Configure the license key on the ReductStore instance with one of the following settings:

- Set `RS_LICENSE` to the complete license document content.
- Set `RS_LICENSE_PATH` to the path of a mounted license file.

Configure only one license source. If both are set, ReductStore rejects the ambiguous configuration and starts without a valid license. See **[License Configuration](/docs/configuration#license-configuration)** for details.

## Usage reporting

## Manage your subscription

Manage or cancel the subscription through the customer portal. Open the portal from the **[Pricing page](/pricing)**. Cancellation takes effect at the end of the current billing period, and the license stays active until then.
