## Configure the license key

Configure the license key on the ReductStore instance with one of the following settings:

- Set `RS_LICENSE` to the complete license document content.
- Set `RS_LICENSE_PATH` to the path of a mounted license file.

Configure only one license source. If both are set, ReductStore rejects the ambiguous configuration and starts without a valid license. See **[License Configuration](/docs/configuration#license-configuration)** for details.
